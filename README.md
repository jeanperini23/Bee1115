# Beecrowd 1115 - Quadrantes (C#)

## 📌 Sobre o Desafio
O desafio exige a leitura de coordenadas cartesianas $(X, Y)$ para determinar a qual quadrante do plano cartesiano cada par pertence.

## ⚙️ Como funciona a lógica
1. O programa faz a leitura inicial dos dois números inteiros ($X$ e $Y$).
2. Utiliza uma estrutura de repetição `while` combinada com operadores lógicos para manter o fluxo ativo.
3. **Condição de Parada:** O programa encerra a execução automaticamente se qualquer um dos valores digitados for igual a `0`.
4. Caso contrário, imprime o quadrante correspondente (Primeiro, Segundo, Terceiro ou Quarto) e repete o processo.
